笔记存储格式

笔记数据怎么存在磁盘上？影响编辑、版本管理、协作等方方面面

A

纯文件系统

每个笔记是一个文件（.md / .mind.json），目录结构即树结构。可以直接用 git 管理，和代码仓库无缝配合，任何编辑器都能打开。

例：notes/算法/排序分析.mind.json , notes/算法/复杂度分析.md

B

SQLite 数据库

所有笔记存为一个 .db 文件，支持复杂查询（按标签、映射关系检索），但失去直接用文本编辑器打开的能力。

C

混合模式：文件为主 + 索引数据库

笔记文件（.md / .mind.json）以目录树存于磁盘，同时自动维护一个 SQLite 索引用于快速检索映射关系。文件是"真相源"，数据库是缓存。
