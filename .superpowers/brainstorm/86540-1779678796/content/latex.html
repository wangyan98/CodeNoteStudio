"树状 LaTeX 公式" 是什么？

这个描述可以有不同的理解方式

A

思维导图节点中的公式

思维导图的每个节点可以包含 LaTeX 公式（行内或块级），公式是节点内容的一部分。树状是指节点之间的父子推导关系。

例：父节点 "主定理" → 子节点 "T(n) = aT(n/b) + f(n)" → 子子节点 "Case 1: f(n) = O(n^{log_b a - ε})"

B

公式推导树 / 证明树

一种特殊类型的思维导图，专门用于数学推导。每个节点是一个公式步骤，父子关系表示推导方向，自动编号。

类似自然演绎证明树，但更通用，用于展示公式之间的推导过程

C

两者都有

思维导图节点可以嵌入 LaTeX（常规用法），同时有一种"推导模式"可以显示节点间的公式推导关系
