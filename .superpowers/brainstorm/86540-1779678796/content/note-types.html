笔记类型与嵌套关系

我理解有两种核心笔记类型，以及它们之间的嵌入关系——这样对吗？

笔记类型关系模型
🧠 思维文档树 (.mind.json)
根节点
├─ 子节点 A (可直接写 MD 内容)
├─ 子节点 B (LaTeX 公式)
├─ 🔗 嵌入 MD 文件 → 复杂度分析.md
└─ 🔗 嵌入子思维导图 → 子主题.mind.json
每个节点可以有标题、正文（MD/LaTeX）、代码函数映射
📝 Markdown 笔记 (.md)
# 标题
正文内容...
$$T(n) = 2T(n/2) + O(n)$$
[[嵌入: 另一个文档.md]]
[映射: quicksort() in sort.c]
MD 文件可以通过特殊语法嵌入其他 MD 文件
🔄 嵌入是 引用关系：被嵌入的文件独立存在，修改一处处处更新
A

对，就是这个模型

两种核心类型（思维文档树 + MD），通过引用嵌入互相组合

B

大致对，但嵌入行为不对

嵌入不是引用，而是复制/内联到父文档中

C

还有其他笔记类型需要加入

除了思维导图和 MD，还有其他格式
