嵌入式文件内容应该在哪里渲染？

当一个 mind.json 节点的 content 中包含 [[path/to/file.md]] 引用时，被引用文件的内容应该显示在哪里？

A

方案 A: 在编辑面板中渲染

保持 Canvas 节点为简洁的矩形标题，当选中节点时，在底部 NodeEditPanel 中渲染 content + 嵌入文件内容。类似当前 MD 预览模式。

优点

  • 不改变现有 Canvas 布局
  • 嵌入内容可滚动、可交互
  • 实现成本最低

缺点

  • 需要选中节点才能看到嵌入内容
  • 无法同时看到多个节点的嵌入
B

方案 B: 在 Canvas 节点下方展开渲染

在 SVG 树图中，每个有嵌入内容的节点下方展开一个 HTML 内容区域（使用 foreignObject），直接显示嵌入文件的渲染内容。

优点

  • 一目了然，所有嵌入内容可见
  • 符合"思维导图"的整体视图理念

缺点

  • foreignObject 在 SVG 中性能较差
  • 嵌入内容多时视图混乱
  • 缩放/拖拽复杂度高
C

方案 C: 混合方案 — Canvas 显示缩略标记 + 编辑面板显示完整内容

在 Canvas 节点上显示嵌入标记（如 📎 图标 + 文件名），选中节点后在编辑面板渲染完整嵌入内容。

优点

  • Canvas 保持简洁
  • 用户可感知哪些节点有嵌入
  • 选中后可查看完整渲染

缺点

  • 比纯方案 A 稍复杂
  • 仍需选中才能看详情
