浮动定位按钮 — 位置和样式方案

当用户平移/缩放后找不到节点时，点击按钮回到根节点位置

场景说明

三种图（思维导图 mind.json、序列图 seq.mermaid、网络图 net.json）在渲染时，用户可能通过平移/缩放使视口偏离原有内容区域太远，需要一个快速定位回到「根节点」或「视图中心」的按钮。

方案 A — 右下角圆形按钮（推荐）

圆形定位按钮，右下角悬浮，带定位图标
Root
Child A
Child B

优点

  • 圆形最小化干扰，不遮挡内容
  • 位置固定右下角，直觉可发现
  • 实现简单，三种图统一使用

缺点

  • 小图标可能不够明显

方案 B — 带文字的矩形浮动按钮

右下角矩形按钮，图标 + "定位" 文字
Root
定位

优点

  • 文字提示明确，用户一看就懂
  • 比纯图标更容易发现

缺点

  • 占据更多空间，对纵向布局有轻微遮挡
  • 文字国际化问题（目前仅中文）

方案 C — 半透明悬浮操作栏

右下角半透明面板，含定位 + 缩放按钮组
+
−

优点

  • 可以顺便加上缩放控制，功能更完整
  • 半透明设计不突兀

缺点

  • 实现复杂度较高
  • 缩放操作已有滚轮/手势，加按钮意义不大
