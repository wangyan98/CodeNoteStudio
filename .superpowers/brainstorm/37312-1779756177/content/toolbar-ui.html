Add Repo Flow

1. Click + Add Repo in the toolbar

2. Native folder picker opens → select a code repository

3. Path appears as a chip in the toolbar

4. notebook.json is saved with the new repo

5. CodeDirectory refreshes to show all repos

Click a repo chip to focus/filter the CodeDirectory to that repo. Right-click → Remove.
