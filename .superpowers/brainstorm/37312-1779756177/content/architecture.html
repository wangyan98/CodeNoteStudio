Workspace Architecture

Approach 1: Config-in-Notes — single directory, config lives alongside notes

Directory Structure

~/my-notes/                   ← user picks this via native folder dialog
├── notebook.json              ← config file lives here
├── algorithms.md
├── system-design.md
├── projects/
│   └── todo.md
└── .index.db                  ← SQLite index (hidden)

notebook.json Format

{
  "name": "My Notes",
  "notesPath": "./",           ← default: workspace root
  "codeRepos": [
    {
      "path": "/Users/wangyan/projects/algo",
      "commit": "",
      "lsp": { "language": "cpp", "command": "clangd" }
    }
  ]
}

Startup Flow

App Launch
  │
  ├─ Read ~/Library/.../code-note-studio/workspace.json
  │    └─ { "lastPath": "/Users/wangyan/my-notes" }
  │
  ├─ Path exists?
  │    ├─ YES → open workspace, load notebook.json
  │    └─ NO  → show landing page ("Open Folder" button)
  │
  └─ Window loads with 4-panel layout + workspace toolbar

User switches workspace:
  Toolbar "Open Folder" → native dialog → workspace:open IPC
    → save new path to workspace.json
    → load notebook.json
    → refresh UI

IPC Channels (new)

Channel Direction Purpose
workspace:open renderer → main Set workspace path, load config, init DB
workspace:get-current renderer → main Get current workspace path (replaces unused getProjectPath)
dialog:select-folder renderer → main Open native folder picker dialog
