画布节点交互 (Canvas Node Interactions)

在 D3.js 树图中，用户如何对节点执行操作？

A

双击编辑标题 + 选中

双击节点 → title 变为可编辑输入框，同时节点被选中（底部面板加载该节点的 content）。

B

右键上下文菜单

右键节点 → 弹出上下文菜单：添加子节点、添加兄弟节点、删除节点、切换折叠。标准桌面交互模式。

C

节点 Hover 按钮

鼠标悬停节点 → 节点两侧出现 +/- 按钮（添加子节点/删除），点击选中节点打开底部面板。

D

拖拽重新排列

拖拽节点到其他节点上 → 重新设置父子关系（reparent）。拖拽到节点之间 → 调整同级顺序。

E

键盘快捷键

Tab 添加子节点 / Enter 添加兄弟节点 / Delete 删除 / Space 折叠展开 / 方向键导航选中。面向键盘用户。
