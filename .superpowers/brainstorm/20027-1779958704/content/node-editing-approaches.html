节点正文编辑 (Node Content Editing)

思维导图节点有两个文本层：title（标题，显示在节点上）和 content（正文，Markdown/LaTeX）。在画布编辑模式下，content 应该如何编辑？

A

内联弹出 (Inline Popover)

双击节点 → 节点下方弹出小型 Markdown 编辑面板（带实时预览切换），编辑完成后点击外部关闭。适合轻量级内容编辑。

B

侧边面板 (Side Panel)

选中节点 → Panel 2 右侧出现编辑面板，包含 title 输入框 + Monaco 编辑器（编辑 Markdown 正文内容 + embedRefs）。类似 Notion 的侧边详情面板。

C

内联+面板组合 (Inline + Panel)

节点上双击 title 直接编辑，右键或快捷键打开侧边面板编辑 Markdown content。标题快速编辑走内联，正文编辑走面板。
