When you double-click a function name in CodeViewport, what should happen?

The goal: select a symbol, then drag it to Note Viewport to create @ref

Current State (for reference)

Code Viewport — read-only Monaco editor
export function getUserById ( id : string ) { // ... }

Clicking Symbols button opens a modal picker — 2 clicks + search + select.
Double-click on a function name would be: 1 action = select

A

Gutter Drag Handle

Double-click highlights the function name and shows a drag handle icon (⠿ or ✥) in the glyph margin next to the line. User drags from the handle.

⠿ getUserById (id: string) { ... }

Pros

  • Clear affordance — "this is draggable"
  • Doesn't interfere with text selection

Cons

  • Small hit target for drag
  • Requires Monaco glyph margin customization
B

Floating Pill / Badge

Double-click pops up a floating chip/pill near the selected function showing its name + kind. The pill itself is the drag source.

getUserById (id: string) { ... }
⠿ fn getUserById

Pros

  • Highly visible, obvious what's selected
  • Large drag target

Cons

  • May obscure nearby code
  • Needs positioning logic to stay in viewport
C

Inline Highlight + Direct Drag

Double-click highlights the function name with a background color. User drags directly from the highlighted text in the editor.

getUserById (id: string) { ... }

Pros

  • Simplest implementation — just Monaco decorations
  • Feels natural: "grab what's highlighted"

Cons

  • Conflicts with Monaco's native text selection drag
  • Less obvious "this is draggable" affordance
