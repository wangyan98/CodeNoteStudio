Web 导出：两种模式

静态站点 + 实时服务，覆盖不同场景

📄 静态导出
生成纯 HTML/CSS/JS 文件包，可部署到任何静态服务器或直接打开
✅ 完全独立，无需桌面端运行
✅ 可分享、托管、归档
❌ 无 LSP 跳转
❌ 代码块是导出时的快照
❌ 思维导图不可交互
🌐 Live Server 模式 (推荐)
桌面端启动内置 HTTP + WebSocket 服务，浏览器访问获得完整交互体验
✅ LSP 实时跳转（通过 WebSocket）
✅ 代码始终展示最新仓库版本
✅ 思维导图可交互展开/折叠
✅ 多设备局域网访问
⚠️ 需要桌面端保持运行
⚠️ 只读（不提供编辑功能）
Live Server 通信架构
浏览器  ← HTTP/WebSocket →  Electron 主进程 (Express + ws)  ← N-API →  C++ LSP Client  ↔  LSP Server (clangd / pyls)
浏览器 UI 通过 WebSocket 请求函数定义/引用/跳转 → Electron 转发给 C++ LSP Client → LSP Server 返回结果 → 渲染跳转目标
A

两种模式都要

静态导出 + Live Server 模式，各有用处

B

只要 Live Server

不需要静态导出，Web 模式就靠 Live Server
