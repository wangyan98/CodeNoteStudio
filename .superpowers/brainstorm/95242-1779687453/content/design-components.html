4 栏组件设计 & 数据流

每个面板的职责和交互

面板职责
📁 笔记目录 (Panel 1)
职责：展示所有笔记的树状目录
操作：新建/删除/重命名/拖拽排序
交互：点击 → Panel 2 打开笔记
过滤：按类型筛选 (思维导图/MD/推导树)
搜索：笔记标题模糊搜索
📝 笔记视口 (Panel 2)
职责：编辑/查看当前笔记
MD 模式：Monaco Editor + 预览
思维导图：D3.js 交互式树
推导树：带编号的公式树
嵌入：内联渲染被嵌入的子笔记
映射：高亮显示代码引用链接
💻 代码视口 (Panel 3)
职责：展示代码文件内容
编辑器：Monaco Editor (只读)
跳转：点击映射链接 → 定位到函数定义
高亮：当前映射的函数高亮显示
Git 信息：显示当前 commit SHA
多 Tab：可打开多个代码文件
📂 代码目录 (Panel 4)
职责：展示关联仓库的文件树
交互：点击文件 → Panel 3 打开
标记：有映射的文件显示特殊图标
过滤：支持文件类型过滤
多仓库：切换不同关联仓库
核心交互流程
打开笔记 → 查看代码
Panel 1 选笔记 → Panel 2 渲染内容 → 点击 @map 链接 → Panel 3 跳转到代码函数 → Panel 4 展开对应文件
浏览代码 → 查找笔记
Panel 4 浏览代码树 → Panel 3 查看代码 → 右键 "查找相关笔记" → Panel 1 高亮关联笔记 → Panel 2 打开
建立映射
Panel 2 选中笔记节点/文本 → 点击 "关联代码" → 弹出函数选择器 (由 C++ LSP 提供列表) → 选择函数 → 映射写入 SQLite 索引
