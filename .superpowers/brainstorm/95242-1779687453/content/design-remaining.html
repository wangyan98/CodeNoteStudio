Web 只读导出 & 文件存储结构

Web 只读导出
导出方式：生成静态 HTML 站点（所有笔记 + 思维导图 + 代码快照渲染为自包含页面）
📦 导出内容
  • 所有笔记渲染为 HTML
  • 思维导图 → 静态 SVG/HTML 树
  • LaTeX → KaTeX 预渲染
  • 代码块 → 带高亮的静态代码
  • 代码映射 → 代码快照（导出时的版本）
🚫 不支持
  • 编辑功能
  • LSP 实时跳转
  • 创建/删除笔记
  • 映射管理
