交互细节

正常流程

  • 点击历史项 → 校验目录存在且含 notebook.json → 打开
  • Create → 选父目录 → 输入名称 → 自动创建文件夹
  • Open Workspace → 选目录 → 校验 notebook.json → 打开或拒绝

异常处理

  • 历史项目录已删除 → toast 提示 + 自动移除
  • Open 非项目目录 → toast "Not a valid workspace"
  • 历史列表空 → 隐藏 "Recent Workspaces" 区域
