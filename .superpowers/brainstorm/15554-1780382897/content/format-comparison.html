JSON Schema vs DSL — Comparison

How would editing a ResNet block feel in each approach?

A: JSON Schema (.net.json) — RECOMMENDED
{
  "type": "net",
  "version": 1,
  "name": "ResNet Block",
  "blocks": [{
    "id": "resblock1",
    "name": "ResidualBlock",
    "repeat": 3,
    "layers": [
      {
        "id": "conv1",
        "type": "Conv2d",
        "params": {
          "in_channels": 64,
          "out_channels": 64,
          "kernel_size": 3,
          "stride": 1,
          "padding": 1
        },
        "codeMapping": {
          "raw": "models/resnet.py:Block.conv1:42",
          "functionName": "conv1",
          "filePath": "models/resnet.py",
          "startLine": 42
        }
      },
      {
        "id": "bn1",
        "type": "BatchNorm2d",
        "params": { "num_features": 64 },
        "codeMapping": {
          "raw": "models/resnet.py:Block.bn1:43",
          "functionName": "bn1",
          "filePath": "models/resnet.py",
          "startLine": 43
        }
      },
      {
        "id": "relu1",
        "type": "ReLU",
        "params": { "inplace": true },
        "codeMapping": {
          "raw": "models/resnet.py:Block.relu:44"
        }
      }
    ],
    "connections": [
      { "from": "conv1", "to": "bn1" },
      { "from": "bn1", "to": "relu1" },
      { "from": "relu1", "to": "conv2" }
    ],
    "skipConnections": [
      { "from": "#block_input", "to": "#block_output" }
    ]
  }]
}

Pros

  • Matches existing .mind.json / .derive.json pattern
  • Reuses note-service read/write/validate pipeline
  • Reuses CodeMapping[] from derive nodes
  • Easy for future agents to generate
  • Type-safe validation

Cons

  • Verbose to hand-write
  • Need an editor panel to fill params
B: DSL (.net.txt)
network ResNetBlock {

  block ResidualBlock [repeat=3] {
    Conv2d(in=64, out=64, k=3, s=1, p=1)
      -> BatchNorm2d(64)
      -> ReLU(inplace=true)
      -> Conv2d(in=64, out=64, k=3, s=1, p=1)
      -> BatchNorm2d(64)

    input -> + -> ReLU -> output  # skip

    # Source mappings as annotations
    @ref(conv1: models/resnet.py:42)
    @ref(bn1: models/resnet.py:43)
    @ref(relu: models/resnet.py:44)
  }
}

Pros

  • Concise, reads like PyTorch
  • Quick to write

Cons

  • Custom parser needed (lexer + grammar)
  • No existing project pattern to reuse
  • Harder for agents to generate precisely
  • Validating + error messages is custom work
  • Must convert to IR for renderer anyway
