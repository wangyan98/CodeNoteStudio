Key Interactions

Mini DAG

Auto-laid-out as a horizontal tree using CSS flexbox. Each node is a small pill with step number and title. Arrows show derivation direction. Clicking a pill scrolls to that node.

Drag Reorder

The numbered circle is the drag handle. Drag a node up/down to reorder. Step numbers, DAG preview, and dropdowns auto-update after the drop.

Live KaTeX

The preview area below the textarea re-renders on every keystroke via KaTeX. Debounced at 150ms to avoid jank with complex formulas.

Inline Insertion

A subtle '+' button appears between nodes on hover, and a fixed '+ Add Step' button sits at the bottom of the list.
