Design Section 4 — v1 Migration & Implementation Scope

v1 → v2 Migration

打开 v1 .net.json 时自动转换，用户无感：

// Pseudo:
migrateV1toV2(doc):
  nodes = [
    { kind:'input', label:'Input', inputShape: doc.inputShape },
    ...doc.blocks.flatMap(blockToNodes),
    { kind:'output', label:'Output' },
  ]
  edges = [
    // block内部按layers数组顺序生成forward edges
    ...block.layers.sliding(2).map([a,b] => forwardEdge(a, b)),
    // skipConnections → style:'skip' edges
    ...block.skipConnections.map(c => skipEdge(c.from, c.to)),
    // doc.connections → forward edges between blocks
    ...doc.connections.map(c => forwardEdge(c.from, c.to)),
  ]

Out of scope (保持现状或后续)

  • NetworkPalette — 不变，拖拽 pill 仍然工作
  • Layer catalog — 不变，layerDef 仍然查 catalog 获取颜色和参数
  • Code mapping / @ref — 不变，codeMapping 在 GraphNode 上仍然支持
  • Block 嵌套渲染 — collapse/expand block 内部子图（后续迭代）
  • 节点手动拖拽定位 — 不在本次范围（选了纯自动布局）
  • Undo/redo — 不在本次范围
