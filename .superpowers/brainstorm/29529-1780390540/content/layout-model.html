Node layout — automatic or manual?

画布上的节点和边如何排列

A

自动 DAG 布局（推荐）

使用 dagre 或类似算法自动计算节点位置。

从左到右（或从上到下）排列，最小化边交叉。

添加/删除节点后自动重排。

优点：零手动工作，始终整洁。适合快速迭代网络结构。

缺点：丧失精确的位置控制。

B

手动拖拽定位

节点可自由拖拽到任意位置，位置数据持久化。

适合需要精确控制布局的场景（比如画复杂的多分支图）。

优点：完全控制。

缺点：每次加节点都要手动调整位置，繁琐。

C

自动为主 + 手动微调

默认自动 DAG 布局，用户可以拖拽节点覆盖位置。

有一个 "Auto Layout" 按钮可随时重新自动排列。

优点：兼顾效率和灵活。

缺点：实现复杂度最高。
