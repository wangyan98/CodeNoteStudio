How should multiple inputs work?

不同的输入来源（文本提示词、图像、噪声等）如何建模

A

Input 作为一等节点（推荐）

Input 是画布上的实际节点，有类型、名称、shape 标注。

多个 Input 节点可以分别连接不同的 block。

  [Prompt:text] ──→ CLIP ──→ text_emb ─┐
                                       ├──→ UNet → ...
  [Image:image] ──→ VAE ──→ latents ──┘

优点：直观，所见即所得。和 layer/block 统一的连接方式。

B

Input 数组 + target 引用

document 上维护一个 inputs: [{name, shape, connectsTo}] 数组。

每个 input 通过 connectsTo 指向目标 block/layer，不渲染为独立节点。

优点：数据结构简单。

缺点：不够直观，和全图模型不一致。
