How should users create connections between nodes?

在全图模型下，每条边都需要显式创建

A

端口拖拽连线

节点右侧有输出端口（小圆点），左侧有输入端口。

从输出端口拖拽到目标节点的输入端口创建连线。

类似 Blender/Unreal 的材质编辑器。

优点：直观，所见即所得。

缺点：需要精确的鼠标操作，SVG 事件处理较复杂。

B

编辑面板下拉选择（推荐）

选中一个节点后，在底部编辑面板中通过下拉菜单选择其输入来源。

所有可用上游节点在下拉列表中可选。

优点：实现简单，不容易出错。适合文本驱动的工作流。

缺点：不如拖拽直观，看拓扑需要切换到画布。

C

两者都支持

端口拖拽为主要方式，编辑面板的 connection 列表作为补充/查看。

优点：最佳体验。

缺点：实现量最大。
