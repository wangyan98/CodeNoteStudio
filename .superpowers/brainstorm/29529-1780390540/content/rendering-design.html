Design Section 2 — Rendering & Layout

Canvas 从垂直线性渲染 → DAG 自动布局 + 自由连线

Layout Engine: dagre

dagre 是最成熟的 JS DAG 布局库（6.5k stars），已有 D3 集成方案：

  • 输入：nodes (含尺寸) + edges → 输出：每个 node 的 {x, y} 坐标
  • 支持 rankdir: TB (上→下) 或 LR (左→右)
  • 自动处理层级分配、边交叉最小化、节点居中对齐

渲染流程

NetworkCanvas render() 新流程
1. 收集所有可视节点（展开的 blocks 内 children 提升到顶层）
2. 计算节点尺寸（根据 label 文本估算 rect 宽高）
3. 调用 dagre.layout(g) 计算位置
4. D3 渲染：
   a. edges → <path> 曲线（forward: 直线 + 箭头, skip: 贝塞尔虚线 + 箭头）
   b. nodes → <g> 含 rect + label + 端口圆点
   c. input/output 节点 → 特殊样式（圆角更小、颜色更浅）
   d. block 节点 → 虚线边框容器，内含子图
5. 应用 zoom transform（已有）

Node rendering by kind

Kind Shape Color Ports
input 小圆角矩形 #f5f5f5 浅灰 仅右侧输出端口
