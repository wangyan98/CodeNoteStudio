Connection model — keep defaults or go full graph?

Block 内部的 layer 排列和连接方式，决定了编辑体验的复杂度

A

Hybrid（推荐）— 保持默认顺序 + 显式连接覆盖

Block 内 layers 数组仍然按顺序自动串联（简单网络无额外工作）。

当需要分叉/合并/skip 时，通过 connections 数组显式声明，覆盖默认的线性连接。

跨 block 的 skip connection 通过 document.connections 声明。

优点：简单网络保持简洁，复杂结构有逃生口。改动最小。

B

全图模型 — 所有连接必须显式声明

去掉数组顺序的隐含连接，每条边都是显式的 Connection(from, to)。

Layer 排列变为自由画布，无默认顺序。

优点：最大灵活性。支持任意拓扑。

缺点：简单线性网络也需要手动连接每个节点。编辑负担大。
