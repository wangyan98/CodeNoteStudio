Design Section 3 — Connection UI & Interaction

两种方式创建连接：端口拖拽 + 编辑面板

A. 端口拖拽连线

  1. 鼠标悬停节点 → 端口圆点显示（默认半透明，hover 时高亮）
  2. 从输出端口（节点右侧）按下拖拽 → 出现临时橡皮筋线跟随鼠标
  3. 拖到目标节点的输入端口（节点左侧）松开 → 创建 edge
  4. 拖到空白区域松开 → 取消操作
  5. 已存在的 edge，点击选中后按 Delete 删除

实现：SVG <line> 作为 drag ghost，mousemove 更新终点坐标，mouseup 时命中检测目标端口

B. 编辑面板连接管理

选中节点后，底部面板显示：

  • Input connections — 列表显示所有入边，每项：source 节点名 + 删除按钮
  • Add input — 下拉菜单列出所有可作为上游的节点（排除自身和已连接项）
  • Output connections — 列表显示所有出边（只读，从 target 面板管理）

输入端口对 input 节点不可用；输出端口对 output 节点不可用

C. 节点新增 & 删除

  • 添加 layer：从 palette 拖拽 pill 到 canvas → 创建 node + 自动连接（如已有选中节点，连到它后面）
  • 添加 input/output：toolbar 按钮 "+ Input" / "+ Output"
  • 添加 block：已有 "+ Add Block" 按钮，改为创建 kind='block' 的 node
  • 删除节点：选中 + Delete → 删除 node + 所有相关 edge
